Pattern 1 · 현재완료 진행형

have / has + been + -ing
  • 과거 시작 → 현재까지 계속 진행 중
  • for + 기간 (for two hours / for a week)
  • since + 시점 (since 2010 / since Monday)
  • ⚠ 상태동사(know/want/like/have)는
       현재완료 진행형 ✗ → 현재완료만 ✓
  • ⚠ 부정문 어순: has not been -ing
  • ⚠ been ≠ being (been이 올바름)

Pattern 2 · 의문사 + to부정사

의문사 + to + 동사원형
  • 문장에서 목적어 역할 (명사구)
  • how to ~하는 방법 / ~하는 법
  • what to 무엇을 ~할지
  • where to 어디서[어디로] ~할지
  • when to 언제 ~할지
  • = 의문사 + 주어 + should + 동사원형
