Pattern 1 · 관계대명사 계속적 용법

선행사 , who / which + 동사 ~
  • 콤마(,) + who/which → 선행사에 부가 정보 제공
  • who = 사람 선행사 / which = 사물·동물·앞 문장 전체
  • = 접속사 + 대명사로 바꿔 쓸 수 있음
       (who → and/but he/she, which → and/but it)
  • ⚠ that은 계속적 용법으로 쓰지 않는다!
  • ⚠ 계속적 용법 which는 앞 문장 전체를 받을 수 있음
  • ⚠ 관계대명사절 안에 대명사 중복 금지
       (which I liked it → it 삭제)

Pattern 2 · It ~ that (가주어-진주어)

It + be + 형용사 + that + S + V
  • 주어 that절이 너무 길 때 → 뒤로 이동 (진주어)
  • It = 가주어 (해석 ✗)
  • that절 = 진주어 (해석 ✓)
  • ⚠ This / They / He → 가주어는 반드시 It
  • ⚠ that 자리에 what / which / whether → 틀림
  • ⚠ 형용사 자리: true / interesting / surprising
       (truly / amazed / thought → 오류 패턴 주의)
